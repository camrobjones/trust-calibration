# Experiment software

This is the Django application that ran the experiments, included so that readers can see exactly
how trials, conditions, and advisor prompts were put together. It is a snapshot, not a maintained
release. It has not been refactored or tidied for publication.

This is the final deployed revision, from August 2025. Experiments 1 to 3 ran on earlier revisions, so details that changed between experiments, such as interface wording, may differ from what those participants saw. The manuscript's Method sections describe each experiment.

Sensitive information has been redacted and server configuration and databases have not been included.
